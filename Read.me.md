
# Single-Nucleus Transcriptomics Analysis of Striatal Cell Types After In Vivo Gene Editing of the Huntington's Disease Mutation

Jaymz Collins — MSc Applied Bioinformatics and Genomics, Cardiff University

## Overview

This repository contains the complete, reproducible analysis pipeline for a computational reanalysis of the single-nucleus RNA-seq dataset generated by Murillo et al. (2025), extending their MSN-focused analysis to all major striatal cell types. Raw data are retrieved from public repositories; all downstream processing, from Cell Ranger alignment through differential expression, external validation, and restoration analysis, is contained in the scripts described below.

## Requirements

- Cell Ranger v10.0.0
- Python 3 with Scrublet v0.2.3
- R 4.6.0, with: Seurat 5.5.1, harmony 2.0.5, DESeq2 1.52.0, enrichR 3.4, openxlsx, ggplot2, ggrepel, reshape2, SAMtools 1.22.1 (command line)
- A Cardiff University ARCCA Falcon HPC account, or equivalent SLURM-managed cluster

### `Project_Config.txt`

Bash and Python scripts read their project root from this file rather than a hardcoded path. It must exist in **three places**: `PROJECT_ROOT/`, `PROJECT_ROOT/Scripts/`, and `PROJECT_ROOT/Scripts/Cellranger/`. Edit the path on the last line of each copy to match your own directory structure:

```
# Shared configuration file, read by every bash/Python script in this project.
# Contains the root directory of this project on your filesystem.
# Update the path below to match your own directory structure before
# running any scripts.
/path/to/your/Dissertation
```

R scripts use a different, equivalent mechanism: a `PROJECT_ROOT <- "..."` line at the top of each script, clearly marked `# EDIT THIS`.

## A note on reproducibility: clustering non-determinism

Graph-based clustering (the Louvain algorithm, via Seurat's `FindClusters()`) is not guaranteed to be perfectly reproducible across independent R sessions, even with a fixed random seed — a known, documented limitation of this class of algorithm. Independent re-execution of `04_clustering_annotation.R` may therefore not reproduce cluster assignments, and downstream cell-type counts, identical to those reported in this dissertation.

To guarantee exact reproducibility of every result reported in this work, the checkpoint object `merged_seurat_post_cluster_QC.rds` — the direct output of Script 04, after cluster-level quality control — is provided directly in this repository's `Analysis/` folder. Scripts 05 and 06 load this file rather than requiring Script 04 to be re-run. Re-running Script 04 is not required and is not expected to reproduce identical output.

## Pipeline: Bash / Python Stage

Run in this order.

1. **`Build_Ref_Prep.sh`** — decompresses base genome files and combines with the provided custom transgene sequences (`custom_transgenes.fa`, `custom_transgenes.gtf`, encoding Cas9D10A, GFP, and huHTT), producing `Mus_custom_v2.fa` and `Mus_custom_v2.gtf`, with built-in checks confirming mitochondrial and Y-chromosome contigs are present.
2. **`Run_Mkref_V2.sh`** (`sbatch`) — filters the combined GTF to standard countable gene biotypes and builds the final Cell Ranger reference (`Mus_custom_v2`) using `cellranger mkref` v10.0.0.
3. **`Scripts/Cellranger/cellranger_*_array_v2.sh`** (`sbatch`, four scripts) — aligns all 12 samples against `Mus_custom_v2` using `cellranger count` v10.0.0.
4. **`Scripts/Cellranger/cellranger_*_solo.sh`** (`sbatch`, three scripts) — three samples (WT_Cas9_1, WT_Cas9_sg_2, WT_Cas9_sg_3) failed within the original array job submission due to job time limits and are resubmitted individually here.
5. **`Run_Scrublet_V2.py`** — doublet detection for all 12 samples using Scrublet v0.2.3. No random seed was set. Requires `module load SciPy-bundle/2023.11-gfbf-2023b` and `pip install scrublet --user`.

Output for each sample is written to `Cellranger_outputs_v2/{sample}_v2/outs/`; Scrublet output is written to `Scrublet_outputs_v2/{sample}_v2_scrublet.csv`.

## Pipeline: R Stage

Run in this order, in a fresh R session, after setting `PROJECT_ROOT` at the top of each script.

### `01_load_and_QC_filter.R`

Loads raw Cell Ranger outputs for all 12 samples, calculates per-cell QC metrics (mitochondrial percentage, gene count), imports Scrublet doublet predictions, and applies combined per-cell filtering. **Requires:** Cell Ranger outputs, Scrublet outputs (see Bash/Python stage above). **Produces:** `seurat_list_filtered.rds`, `QC_filtering_summary_per_sample.csv`.

### `02_merge_normalise.R`

Merges the 12 QC-filtered objects, adds sample-level metadata (sex, genotype, treatment), and applies SCTransform normalisation. **Requires:** `seurat_list_filtered.rds`. **Produces:** `merged_seurat_with_sex.rds`, `merged_seurat_post_sctransform.rds`.

### `03_dimensionality_reduction.R`

Computes principal components, applies Harmony batch integration, and generates a UMAP embedding. **Requires:** `merged_seurat_post_sctransform.rds`. **Produces:** `merged_seurat_post_umap.rds`.

### `04_clustering_annotation.R`

Clusters the integrated dataset (Louvain algorithm), assigns provisional cell-type labels via marker-based module scoring, and performs full cluster-level quality control (marker specificity, doublet co-expression confirmation, cluster purity), excluding technically compromised clusters. **Requires:** `merged_seurat_post_umap.rds`. **Produces:** `merged_seurat_post_clustering.rds`, `merged_seurat_post_annotation.rds`, `merged_seurat_post_cluster_QC.rds`, and associated summary tables. **Note:** see "A note on reproducibility" above — this script's clustering step is not guaranteed to be bit-for-bit reproducible; the checkpoint it produces is provided directly.

### `05_pseudobulk_DE_and_validation.R`

Runs pseudobulk differential expression (genotype and treatment comparisons, all cell types), threshold sensitivity analysis, exports a supplementary Excel workbook, generates volcano plots, and validates the disease signature against Murillo et al. (2025) and Lee et al. (2020). **Requires:** `merged_seurat_post_cluster_QC.rds` (provided directly — see note above); external validation CSVs (see Data Acquisition above). **Produces:** `DE_results_all_comparisons_postQC.rds`, threshold sensitivity tables, `Supplementary_DE_results_all_celltypes.xlsx`, volcano plots, concordance tables and figure.

### `06_specificity_pathway_restoration.R`

Tests whether the treatment vector itself produces transcriptional changes independent of genotype (off-target specificity check), visualises the resulting interferon signature across all four experimental groups, runs pathway enrichment on the treatment comparison, and performs the restoration analysis (treated R6/1 vs WT). **Requires:** `merged_seurat_post_cluster_QC.rds` (provided directly); `DE_results_all_comparisons_postQC.rds`. **Produces:** off-target results, interferon heatmap, treatment and restoration pathway enrichment results and figures, restoration and shrinkage summary tables.

## Output

All intermediate and final outputs are written to `PROJECT_ROOT/Analysis/`. The figures and tables reported in the dissertation are generated directly by Scripts 04–06, as documented above.
